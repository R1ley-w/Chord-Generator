Usage guide

Getting started

Open the generator, enter a melody, pick a creativity level, then press Generate chords. You will get a chord progression that fits your melody, along with a key and downloadable JSON, MIDI, and audio files.

Entering a melody

There are two ways to enter notes, and they stay in sync.

The note grid

Rows are pitches and columns are beats. Click a cell to place a one beat note at that pitch and time, and click it again to remove it. The grid updates the text box below it automatically.

The text box

Write one note per line as pitch, start beat, and duration. For example: 

C4 0.0 1.0
E4 1.0 1.0
G4 2.0 2.0
B4 4.0 1.0

Pitch is a note name like C4 or Eb5. Start and duration are measured in beats, so a duration of 1.0 is a quarter note. If you leave them out, notes are placed one beat apart.

Creativity levels

LevelBehavior
ConservativeDeterministic and strictly diatonic chords.
BalancedMostly diatonic with occasional tensions.
CreativeChromatic freedom and frequent tensions.
ExperimentalExploratory sampling, tritone substitutions, heavy color.

How it works

The generator detects the key of your melody, finds phrase boundaries, and proposes chords with a Markov chain trained on jazz standards. It then snaps chords toward the key, adds harmonic color, and checks each chord against the melody note before returning the result.

Enabling audio playback

MP3 playback is synthesized from MIDI using FluidSynth. It needs FluidSynth and an MP3 encoder installed on your machine, plus a SoundFont. See the project README for setup steps. Without those, the JSON and MIDI downloads still work.
